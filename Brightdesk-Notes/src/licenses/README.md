# Bundled GNU licence text references

These two standard GNU licence text files are included unchanged for the Estonian and Basque spelling-dictionary entries. Those upstream dictionary package folders declare the licence but do not include a separate per-package `license` file.

- `GPL-2.0.txt` — official text: https://www.gnu.org/licenses/old-licenses/gpl-2.0.txt
- `LGPL-2.1.txt` — official text: https://www.gnu.org/licenses/old-licenses/lgpl-2.1.txt

The dictionary data remains subject to the individual upstream licence expression recorded in `src/dictionary-catalog.json`. The Brightdesk catalogue retains each package's upstream `readme.md` as attribution evidence when installing a dictionary.
