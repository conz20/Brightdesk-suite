# Brightdesk brand and copyright standard

## Official project identity

The public-facing project identity is **Brightdesk** (one word, capital B). Use this spelling consistently in repository names, product documentation, copyright notices, security policies, release notes and visual assets.

Do not place a maintainer's personal name, personal email address or private contact details in public copyright notices, security documents, package metadata or brand artwork.

Brightdesk is the project and brand identity used for public attribution. This wording does not claim that Brightdesk is an incorporated company or registered legal entity.

## Copyright notice

Use this notice for Brightdesk-owned project material where the rights and provenance review confirms Brightdesk is the correct rights-holder label:

`© 2026 Brightdesk`

The equivalent plain-text notice in the MIT licence is:

`Copyright (c) 2026 Brightdesk`

Keep the complete MIT licence text intact. Only the copyright attribution line is project-specific. Do not add "All rights reserved" to the MIT notice or alter the MIT permission, condition or disclaimer paragraphs.

## Software licence and brand rights

- Brightdesk Suite source code and the ten customer product repositories use the MIT License where a root `LICENSE` file is present.
- Preserve the complete MIT notice when redistributing covered source or substantial portions.
- The MIT licence for software does not, by itself, grant permission to use Brightdesk names, logos, product icons or other brand identifiers as though a build were an official Brightdesk release.
- Third-party dependencies, fonts, language resources and other bundled assets keep their own licences and attribution requirements. See `THIRD_PARTY_NOTICES.md` and the relevant asset catalogue.
- Do not add a restrictive licence to code already distributed under MIT. A later licence decision cannot retroactively remove permissions already granted.

## Visual copyright mark

Use `assets/brand/brightdesk-copyright-mark.svg` as the canonical copyright emblem in the Suite README and brand documentation. It is a visual presentation of the standard copyright symbol, not a substitute for the text notice or the MIT licence.

Keep the original SVG vector file. Do not redraw it as a plain letter C, replace the © glyph with a generic C, stretch it, add shadows or effects, or use it as a product application icon.

## Review and release gate

Before a public release, confirm the source and contributor rights for each file attributed to Brightdesk, retain all third-party notices, verify the current licence files, and obtain appropriate legal review for ownership or trademark questions. A project-name attribution is not proof of a legal assignment from a contributor.
