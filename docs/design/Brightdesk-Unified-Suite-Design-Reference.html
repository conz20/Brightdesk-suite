Brightdesk Office Suite · design reference

One suite.
Three strengths. One identity.

The target is a single, coherent desktop experience that combines the useful ideas in Microsoft 365, Adobe Creative Cloud and ArtCraft—without copying their branding or becoming three separate products.
Reference board · 6 November 2026
The design decision

Brightdesk should have one central home, one application catalogue, and one connected set of creative and productivity workspaces. The three references describe different layers of that same product—not three interfaces that users must switch between.

01 · Supplied screenshot

Adobe Creative Cloud

Creative discovery, featured tools, quick-start ideas, updates and recent work in one home surface.
What Brightdesk should take from it

A useful home screen that can surface creation shortcuts, helpful starting points, recently opened local files and suite-level updates. Do not copy its subscription plans, trial offers or cloud-storage model.

02 · Supplied screenshot

ArtCraft Launcher

A branded product catalogue with distinct icons, versions, install state, search, sorting and product actions.
What Brightdesk should take from it

Clear product cards with original icons, version and update information, installed and available sections, plus obvious Open, Install, Update and management actions.

03 · External screenshot reference

Microsoft 365 Home

A central landing page connecting applications with recommended and recently opened work.
What Brightdesk should take from it

One familiar home for app access, search, recent work and quick return to the user's documents. Brightdesk keeps those files local-first rather than introducing cloud dependence.

How the three become one Brightdesk experience

Each reference contributes a different capability. Brightdesk combines them in one information architecture and one visual system.

Microsoft 365 influence

Home and recent work

A central Home view, global search, locally stored recent files, quick access and navigation across the suite.

Creative Cloud influence

Discover and create

Featured creative workflows, useful quick-start actions, curated tips and shortcuts into the right Brightdesk workspace.

ArtCraft influence

Manage the product family

One catalogue for all ten products, original icons, accurate versions, install state, updates and product management.

Design rules for the combined suite

One identity, not three brands

Use original Brightdesk branding, original product icons, shared typography, spacing, controls and navigation. Borrow useful interaction patterns—not logos or distinctive proprietary artwork.

One home, with contextual destinations

Home is the user's starting point. App Centre manages the ten products. Opening a product enters its dedicated workspace while retaining the same suite shell.

Creative and productivity together

Creation shortcuts and featured workflows can sit alongside documents, spreadsheets, presentations, notes, data, tasks and projects.

Local-first and subscription-free

Do not import Adobe's plan cards, trials, paid credits, cloud storage, or Microsoft cloud-service dependencies. Keep Brightdesk's local-first product boundary.
