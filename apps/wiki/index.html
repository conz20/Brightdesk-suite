Getting Started / Architecture

Architecture Overview

The Brightdesk Office Suite is engineered as an npm workspaces monorepo containing 10 standalone productivity applications and a shared UI design package.

Core Principles

  • Standalone Apps: Each application operates independently with dedicated app shells and tooling.
  • Enterprise Polish: Styled to match Microsoft 365, Adobe, and Craft design standards.
