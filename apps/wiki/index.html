Getting Started / Architecture

Architecture Overview

The Brightdesk Office Suite coordinates the ten approved desktop products with shared interface and engineering components.

Core Principles

  • Standalone Apps: Each application operates independently with dedicated app shells and tooling.
  • Enterprise Polish: Uses Microsoft productivity software as the primary experience reference and Adobe Creative Suite as a secondary reference for creative capabilities; all Brightdesk implementations and assets remain original, and no Adobe applications or services are included or required.
