# Brightdesk Database

<p align="center"><img src="../../assets/icons/database.svg" alt="Brightdesk Database application icon" width="96" height="96"></p>

Create local tables, define fields, manage records and export structured data.

This is the Database feature area within the Brightdesk Office Suite. The approved product lineup and shared design rules are documented in the [main README](../../README.md) and [visual standard](../../docs/BRIGHTDESK_VISUAL_STANDARD.md).


## Customer Help

The shared Brightdesk Suite shell provides a small, discreet **Help** link near the bottom of the persistent sidebar. For Database, it opens the central read-only guide at `https://help.brightdesk.com/products/database.html` in the customer's normal browser. This is the reserved customer address, not a live or verified website yet. Approved Wiki guide updates appear the next time Help is opened and do not require a new Brightdesk installer. Opening Help sends no document or product data.
